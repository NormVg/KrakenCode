# UI

> How grok-build renders its terminal interface: the pager, markdown rendering, Mermaid diagrams, and scrollback blocks.

## 1. The Pager

**File:** `crates/codegen/xai-grok-pager/src/`

The pager is the terminal UI framework. It is a full-screen terminal application built on `ratatui` that provides:

- Real-time conversation rendering
- Tool call status displays
- Workflow visualizations
- Slash command input
- Permission prompts
- File diff viewing

### Pager Architecture

│                    Pager App                         │

## 4. Mermaid Diagram Rendering

**File:** `crates/codegen/xai-grok-mermaid/src/`

Renders Mermaid diagram source to rasterized PNG, behind a swappable `MermaidEngine` trait.

### Pipeline (`lib.rs:10-31`)

```
1. A MermaidEngine turns Mermaid source into SVG
2. rasterize() converts SVG to PNG with resvg/usvg/tiny-skia
   - No remote/file resolvers (safe over untrusted input)
   - Bundled font (deterministic across machines)
```

### Crash Isolation (`lib.rs:19-31`)

Mermaid source is untrusted model/tool output. `render_checked()` enforces a source-size limit and converts engine panics to `MermaidError`. The real crash isolation is **out of process** — the pager renders each diagram in a short-lived child process (`run_with_timeout` and `mermaid_worker`), so a panic or runaway render is contained to the child.

### Engines (`lib.rs:47-57`)

| Engine | Description |
|:-------|:------------|
| `PureRustEngine` | Default, offline, pure-Rust (vendored dagre-based `mermaid-to-svg`) |
| `MmdcEngine` | Optional, uses external `mmdc` CLI (never selected automatically) |

### Themes (`lib.rs:65-92`)

| Theme | Surface Color |
|:------|:--------------|
| `MermaidTheme::Light` | `#FAFAFA` |
| `MermaidTheme::Dark` | `#18181B` |

### Render Limits

**File:** `engine.rs`

`RenderLimits` with source-size limit. `MAX_OUTPUT_MEGAPIXELS` caps output area.

## Key Takeaways for Kraken

1. **Separate rendering from data** — The markdown core crate provides primitives shared across contexts (pager, tests, other consumers)
2. **Out-of-process crash isolation** — Render untrusted Mermaid in a child process so panics don't kill the main app
3. **No remote resolvers** — Mermaid rendering uses no remote/file resolvers and a bundled font for safety and determinism
4. **Phase trail visualization** — Show workflow progress with a compact `✓ ● ○` notation
5. **Scrollback blocks** — Compose the conversation from typed blocks (message, tool, workflow, diff) for flexible rendering
6. **ACP handler pattern** — Centralized event ingestion from the agent session, dispatched to view updaters
7. **Source maps** — Map markdown positions to terminal positions for cursor tracking and navigation
8. **LaTeX support** — Full LaTeX math rendering with commands, environments, and symbols
9. **OSC 8 hyperlinks** — Use terminal escape sequences for clickable links
10. **PTY harness** — Dedicated PTY management for interactive command execution
